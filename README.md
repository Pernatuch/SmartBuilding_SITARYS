# SmartBuilding — мониторинг датчиков здания

Консольное приложение на C# / .NET 8, демонстрирующее три паттерна проектирования:

- **Abstract Factory** — создание согласованных комплектов устройств базовой и премиальной линеек.
- **Observer** — рассылка показаний панели управления, архиву и системе тревоги.
- **Strategy** — отдельные правила тревоги для температуры, дыма и движения.

## Запуск в Visual Studio

1. Распакуйте архив.
2. Откройте `SmartBuilding.csproj` в Visual Studio 2022 или новее.
3. Убедитесь, что установлен .NET 8 SDK.
4. Запустите проект сочетанием `Ctrl + F5`.

## Запуск из терминала

В каталоге с `SmartBuilding.csproj` выполните:

```bash
dotnet run
```

Показания генерируются случайно. Пороговые значения тревоги находятся в `Patterns/Strategy.cs`.
Регистраторы в этом учебном примере выводят сообщение о сохранении, но не записывают данные в файл или базу данных.
